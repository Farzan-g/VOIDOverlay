# Draft first public release notes

This is a draft based on the current source tree, not a published release or a record of Git history. The project has no Git repository or tagged release history in the inspected workspace.

## Candidate: v0.1.0

- Transparent, always-on-top CPU/GPU telemetry overlay with temperature graphs.
- System-tray controls for visibility, position, lock, click-through, startup, settings, and exit.
- Configurable refresh interval and saved settings.
- Four-corner positioning with independent X/Y offsets and full-screen/work-area edge references.
- CPU temperature sensor selection with a documented preference order and unavailable readings shown as `N/A`.
- Diagnostics mode for hardware sensor and monitor positioning information.
